# **App Name**: Universal Conversion Hub

## Core Features:

- File Upload: Drag-and-drop interface for file uploading, supporting multiple file types (PDF, DOC, TXT, XLS, etc.).
- File Conversion: Conversion tool engine supports PDF to DOC, PDF to TXT, DOC to PDF, and XLS to PDF conversion.
- Download Conversion: Easy-to-find download button after conversion completes, with clear visual feedback on conversion progress.
- Monetization: AdSense integration into the page layout; placement is automatically adapted using an AI tool so it doesn't interrupt the user experience on mobile and desktop views.
- Responsive Design: Automatically adapt display and features to fit different devices, screen sizes, and resolutions.
- Conversion Menu: Navigation menu that lets the user quickly locate and choose the conversion type needed (e.g., PDF to DOC, DOC to PDF).

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to evoke trust and professionalism, referencing document-oriented applications.
- Background color: Very light blue (#E3F2FD), creating a clean, uncluttered workspace.
- Accent color: Analogous light purple (#8E44AD), providing contrast for important CTAs like the download button.
- Body and headline font: 'PT Sans', sans-serif for clean and modern interface
- Clear visual hierarchy with a prominent drag-and-drop area and a straightforward conversion process.
- Flat, minimalist icons representing each file type (PDF, DOC, XLS, etc.).
- Smooth transitions and loading animations to enhance user experience during file uploads and conversions.
